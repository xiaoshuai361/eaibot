# line_cy.py 预期效果与调参说明

## 预期效果

运行后会打开巡线摄像头 `VideoCapture(4)`，发布 `/cmd_vel` 控车。

默认会弹出一个处理图窗口：

```text
line_cy_processed
```

这个窗口不是原始摄像头图，而是二值化后的算法图，叠加了：

```text
绿色矩形：巡线 ROI 区域
灰色竖线：图像中心
蓝色：识别到的黑线分组
青色：实际左/右参考线
紫色：补出来的虚拟线
绿色点：巡线中心点
红色框：停止横线
黄色框：斑马线条纹
顶部文字：状态、follow_mode、停车置信度、lane_width、丢线次数
```

正常双线时，小车应沿两条黑线中间巡迹。

接近路口时，只有检测到“停止横线在斑马线靠车一侧”并连续稳定出现，才停车。停车后按 `turn_cmd` 通过：

```text
straight：正常巡线直行，不强制右补线
left：优先跟左线，补右线左转
right：优先跟右线，补左线右转
```

路口通过不是固定时间盲拐，而是边看线边走，直到双线重新稳定出现后恢复普通巡线。`turn_cmd` 只能写 `left`、`straight`、`right`，写错会报警并按 `straight` 处理。

## line_cy_task.py 九路口任务参数速查

`line_cy_task.py` 是固定九路口任务，路线已经写在代码里：

```text
右、直、右、左、直、左、右、直、右
```

真机运行：

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/robocom_ws/devel/setup.bash
cd /home/eaibot/robocom_ws/src
conda activate ww
python3 line_cy_task.py _debug_view:=true
```

摄像头固定分工：

```text
/dev/video4：巡线
/dev/video0：红绿灯识别，分辨率 320x240
```

程序会在打开摄像头 0 前自动执行以下参数设置：

```bash
v4l2-ctl -d /dev/video0 \
  -c exposure_auto=1 \
  -c exposure_absolute=40 \
  -c white_balance_temperature_auto=0 \
  -c white_balance_temperature=4600 \
  -c exposure_auto_priority=0
```

入口流程是 `ALIGN -> TRAFFIC_WAIT -> MANEUVER`。车辆在停止横条前摆正后保持
停车，此时才加载下面的红绿灯模型；红灯、黄灯或未识别到灯都不会放行，连续
两帧绿灯后立即释放模型并进入路口：

```text
/home/eaibot/handeye-calib/src/model/yolov5/traffic_lights_yolov5n_320_best.onnx
```

现场灯时序为红灯 8 秒、绿灯 20 秒、黄灯 2 秒，程序不按时间猜灯色，只按模型
结果放行。仅在不接红绿灯的台架调试中可临时使用
`_traffic_light_enabled:=false` 跳过等待，正式运行不要关闭。

只跑巡线任务、不启用 YOLO：

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/robocom_ws/devel/setup.bash
cd /home/eaibot/robocom_ws/src
conda activate ww
python3 line_cy_task.py _yolo_enabled:=false
```

启用 YOLO，只看检测框、不让 YOLO 停车：

```bash

cd /home/eaibot/robocom_ws/src
```

当前 `line_cy_task.py` 默认使用新版 320 ONNX 模型：

```bash
/home/eaibot/handeye-calib/src/model/yolov5/merge_new_yolov5n_320_best.onnx
```

这个模型的垃圾类别名是 `recyclable material`、`hazardous waste`，程序会分别按
`可回收垃圾`、`有害垃圾` 打印和保存图片。

默认人群/垃圾桶置信度是 `YOLO_CONFIDENCE = 0.60`，楼宇单独使用
`YOLO_BUILDING_CONFIDENCE = 0.40`。现场楼宇还是漏检时，优先只调：

```bash
python3 line_cy_task.py _yolo_building_confidence:=0.35
```

````text
### 压内边线时优先试这组

如果在内侧圆角压线，先不要动 PID，优先试：

```bash
python3 line_cy_task.py \
  _turn_entry_time:=7.1 \
  _turn_angular:=0.60 \
  _turn_time:=4.0
````

继续压内边线：

```text
1. 先把 _turn_entry_time 加到 7.3
2. 还压线，再把 _turn_angular 降到 0.55，同时 _turn_time 加到 4.3
3. 如果出弯转过头，只减 _turn_time，每次减 0.1 到 0.2
```

`line_cy_task.py` 和 `line_cy_new.py` 的转弯参数建议保持一致，尤其是：
