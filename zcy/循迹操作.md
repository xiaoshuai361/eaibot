# line_cy.py 预期效果与调参说明

## 预期效果

运行后会打开巡线摄像头 `VideoCapture(4)`，发布 `/cmd_vel` 控车。

默认会弹出一个处理图窗口：

```text
line_cy_processed
```

这个窗口不是原始摄像头图，而是二值化后的算法图，叠加了：

```text
绿色矩形：巡线 ROI 区域
灰色竖线：图像中心
蓝色：识别到的黑线分组
青色：实际左/右参考线
紫色：补出来的虚拟线
绿色点：巡线中心点
红色框：停止横线
黄色框：斑马线条纹
顶部文字：状态、follow_mode、停车置信度、lane_width、丢线次数
```

正常双线时，小车应沿两条黑线中间巡迹。

接近路口时，只有检测到“停止横线在斑马线靠车一侧”并连续稳定出现，才停车。停车后按 `turn_cmd` 通过：

```text
straight：正常巡线直行，不强制右补线
left：优先跟左线，补右线左转
right：优先跟右线，补左线右转
```

路口通过不是固定时间盲拐，而是边看线边走，直到双线重新稳定出现后恢复普通巡线。`turn_cmd` 只能写 `left`、`straight`、`right`，写错会报警并按 `straight` 处理。

## line_cy_task.py 九路口任务参数速查

循迹中接入无 Tag 机械臂抓取时，参见：`zcy/循迹调用无Tag抓取.md`。

`line_cy_task.py` 是固定九路口任务，路线已经写在代码里：

```text
右、直、右、左、直、左、右、直、右
```

正式真机运行（开启任务 YOLO、停车判断和红绿灯判断）：

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/robocom_ws/devel/setup.bash
cd /home/eaibot/robocom_ws/src
conda activate ww
python3 line_cy_task.py \
  _debug_view:=true \
  _yolo_enabled:=true \
  _yolo_stop_enabled:=true \
  _yolo_people_stable_frames:=3 \
  _yolo_event_ignore_time:=4.0 \
  _traffic_light_enabled:=true \
  _traffic_light_confidence:=0.55
```

摄像头固定分工：

```text
/dev/video4：巡线
/dev/video2：人偶、垃圾桶和楼宇任务识别
/dev/video0：红绿灯识别，分辨率 320x240
```

人群识别不输出人数。每帧比较“医疗人群”和“普通人群”检测框数，
多的一类连续稳定 3 帧后，只输出“某区识别到医疗人群”或
“某区识别到普通人群”；两类数量相同时继续等待。
人群置信度为 0.60，垃圾桶和楼宇置信度固定为 0.65，无需在启动命令中传入。

## zcy_last 一键比赛任务

新版入口会按开关托管 Astra、MoveIt、手眼 TF、Tag 检测和抓取子进程，但不会启动或关闭底盘。旧 `line_cy_task.py` 继续保留用于回退。

终端 1 单独启动底盘并保持运行：

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/robocom_ws/devel/setup.bash
roslaunch xpkg_bringup bringup_basic_ctrl.launch
```

终端 2 再进入任务环境：

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/robocom_ws/devel/setup.bash
source /home/eaibot/mirobot_ws/devel/setup.bash
source /home/eaibot/handeye-calib/devel/setup.bash
conda activate ww
cd /home/eaibot/robocom_ws/src
```

```bash
# 1. 两种抓取都关闭，保持纯循迹流程
python3 -m zcy_last.main

# 2. 仅开始前执行 B 点有 Tag 抓取
python3 -m zcy_last.main --tag-pick --tag-pick-count 2

# 3. 仅第 3 个路口后执行 A 点无 Tag 抓取
python3 -m zcy_last.main --untagged-pick --untagged-pick-count 3

# 4. B 点和 A 点都执行抓取
python3 -m zcy_last.main \
  --tag-pick --tag-pick-count 2 \
  --untagged-pick --untagged-pick-count 3
```

两个数量参数范围都是 `1..4`，表示必须成功抓取的数量。任一目标失败、目标不足、TF 超时或子进程退出都会永久停车，不会跳过后继续比赛。

默认开关也可直接在 `/home/eaibot/robocom_ws/src/zcy_last/config.py` 顶部修改：

```python
ENABLE_TAG_PICK = False
TAG_PICK_COUNT = 1
ENABLE_UNTAGGED_PICK = False
UNTAGGED_PICK_COUNT = 1
```

除终端 1 的底盘外，正式比赛不要预先手动启动同一套抓取 ROS 节点，也不要另外运行抓取脚本。仅当全部抓取依赖都由人工启动并且需要调试时，才使用：

```bash
python3 -m zcy_last.main --external-ros
```

详细状态机、摄像头切换和日志位置见 `robocom_ws/src/zcy_last/README.md`。
