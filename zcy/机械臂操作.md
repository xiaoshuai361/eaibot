# 机械臂操作速查

真机路径默认是 `/home/eaibot/...`。如果在 WSL 的 `/home/zcy/eaibot/...` 改代码，测试前同步到真机对应路径。

## 1. 通用规则

- 每个 ROS 终端都先 `source /opt/ros/melodic/setup.bash`。
- 机械臂相关终端再 source：

```bash
source /home/eaibot/mirobot_ws/devel/setup.bash
source /home/eaibot/handeye-calib/devel/setup.bash
```

- 底盘终端要 source：

```bash
source /home/eaibot/robocom_ws/devel/setup.bash
```

- 不要同时开键盘控制、巡线控制、底盘对准脚本，避免多个节点抢 `/cmd_vel`。
- 示教时不要手掰机械臂，用 RViz 的 Plan/Execute 到位后，再回脚本终端按 Enter。

### 终端 4：YOLO 实时补白

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/mirobot_ws/devel/setup.bash
source /home/eaibot/handeye-calib/devel/setup.bash
python2 /home/eaibot/handeye-calib/src/tag_yolo_quiet_zone_relay.py \
  --python3 /home/eaibot/anaconda3/envs/ww/bin/python3 \
  --yolo-hz 2.0 \
  --publish-hz 4.0 \
  --confidence 0.1 \
  --box-expand-pixels 5
```

参数含义：

- `--yolo-hz`：YOLO 推理频率。
- `--publish-hz`：发布给 AprilTag 的图像频率。
- `--confidence`：YOLO 置信度阈值。
- `--box-expand-pixels 5`：YOLO 框向外扩大 5 像素后再补白，避免把 tag 黑边裁掉。

看 YOLO 框调试时加：

```bash

```

### 终端 6：底盘自动对准 + 自动抓取放置

这个脚本会先慢速移动底盘，让目标 tag 进入红框；对准后会自动调用 `mirobot_pick_test_tag.py` 抓取和放置。不要再额外开一个终端同时跑 `mirobot_pick_test_tag.py`。

  --drive-speed 0.02 \
  --align-tolerance-px 12 \
  --stable-frames 2 \
  --pick-velocity-scale 0.1 \
  --pick-acceleration-scale 0.1

## 4. 示教和重采

### 采集空闲姿态

在 RViz 里把机械臂移动到比赛等待姿态，Plan/Execute 到位后运行：

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/mirobot_ws/devel/setup.bash
source /home/eaibot/handeye-calib/devel/setup.bash
python2 /home/eaibot/handeye-calib/src/mirobot_pick_test_tag.py \
  --mode teach_idle \
  --preset-file /home/eaibot/handeye-calib/config/tag_pick_place_presets.json \
  --overwrite
```

### 只重采某个 tag 的抓取点

放置点已经准时用这个。把 `--sequence 1` 改成要重采的 ID。

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/mirobot_ws/devel/setup.bash
source /home/eaibot/handeye-calib/devel/setup.bash
python2 /home/eaibot/handeye-calib/src/mirobot_pick_test_tag.py \
  --mode teach_tag_grasp \
  --sequence 1 \
  --preset-file /home/eaibot/handeye-calib/config/tag_pick_place_presets.json \
  --overwrite \
  --assist-front-gap 0.04
```

运行流程：

- 确认 AprilTag 窗口里目标 tag 稳定画框，按 Enter 缓存 tag 位姿。
- 脚本自动移动到 tag 前方安全点；`--assist-front-gap 0.04` 表示离 tag 约 4cm。
- 在 RViz 微调吸盘到抓取接触位置，Plan/Execute 到位后按 Enter 记录。

### 只重采某个 tag 的放置点

只有车上载物仓位置不准时用这个。运行前在 RViz 里把吸盘移动到对应释放位置，Plan/Execute 到位后回终端按 Enter。

```bash
source /opt/ros/melodic/setup.bash

source /home/eaibot/handeye-calib/devel/setup.bash

  --mode teach_tag_place \
  --sequence 1 \
  --preset-file /home/eaibot/handeye-calib/config/tag_pick_place_presets.json \
  --overwrite
```

## 5. 关键检查

AprilTag 是否检测到：

```bash
rostopic echo -n 1 /tag_detections
```

TF 是否完整：

```bash
rosrun tf tf_echo base camera_link
rosrun tf tf_echo base tag_1
```

如果 `base -> tag_1` 没有输出，抓取脚本一定不能正常运行。先检查终端 3 手眼 TF 和终端 5 AprilTag。

吸泵服务：

```bash
rosservice list | grep pump
rosservice call /switch_pump_status true
rosservice call /switch_pump_status false
```

## 6. 常用参数

- `--approach-gap 0.03`：抓取前预抓点距离。目标太靠近机械臂导致规划失败时，可以试 `0.01`。
- `--place-approach-gap 0.02`：放置点上方高度。
- `--assist-front-gap 0.04`：示教辅助点离 tag 多远。
- `--teach-settle-seconds 0.8`：示教按 Enter 后等待多久再采样当前姿态。
- `--motion-settle-seconds 0.25`：动作完成后等待关节状态刷新。
- `--home-after-idle`：每个 tag 抓完后先回 idle，再执行 MoveIt 的 `home`。

正常比赛不需要重标定。只有相机、机械臂、底座位置关系变了才重标定。

```bash

```

```bash
roslaunch easy_handeye publish.launch eye_on_hand:=false tracking_base_frame:=camera_link
```
