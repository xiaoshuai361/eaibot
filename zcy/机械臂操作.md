# 机械臂操作速查

真机路径默认是 `/home/eaibot/...`。如果在 WSL 的 `/home/zcy/eaibot/...` 改代码，测试前同步到真机对应路径。

这次如果改了 `mirobot_ws/src/mirobot_urdf_2`，同步到真机后必须重新编译并重启终端 2：

```bash
cd /home/eaibot/mirobot_ws
source /opt/ros/melodic/setup.bash
catkin_make
```

## 1. 通用规则

- 每个 ROS 终端都先 `source /opt/ros/melodic/setup.bash`。
- 机械臂相关终端再 source：

```bash
source /home/eaibot/mirobot_ws/devel/setup.bash
source /home/eaibot/handeye-calib/devel/setup.bash
```

- 底盘终端要 source：

```bash
source /home/eaibot/robocom_ws/devel/setup.bash
```

- 不要同时开键盘控制、巡线控制、底盘对准脚本，避免多个节点抢 `/cmd_vel`。
- 示教时不要手掰机械臂，用 RViz 的 Plan/Execute 到位后，再回脚本终端按 Enter。
- 比赛抓取前必须完成一次 `640x480` RGB 内参标定并重新完成手眼标定。补白节点发现内参为空会拒绝发布。
- 当前 preset 格式是版本 3。旧版本 1/2 只能保留放置点和 idle，必须重新示教抓取点后才能运行。

### 终端 4：YOLO 实时补白

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/mirobot_ws/devel/setup.bash
source /home/eaibot/handeye-calib/devel/setup.bash
conda activate ww
python2 /home/eaibot/handeye-calib/src/tag_yolo_quiet_zone_relay.py \
  --python3 "$(which python3)" \
  --image-topic /camera/rgb/image_rect_color \
  --yolo-hz 5.0 \
  --publish-hz 8.0 \
  --confidence 0.08
```

参数含义：

- `--yolo-hz`：YOLO 推理频率。
- `--publish-hz`：发布给 AprilTag 的图像频率。
- `--confidence`：YOLO 置信度阈值。
- `1.0/1.0` 不是最快，是一秒只处理一次；如果 `5.0/8.0` 卡顿，再降到 `3.0/6.0`。

看 YOLO 框调试时加：

### 终端 6：底盘自动对准 + 自动抓取放置

这个脚本只沿物块一排慢速移动。YOLO 缓存发布不计入稳定帧；进入红框后会停车，等待底盘稳定，再用一张新的 YOLO 推理确认。Tag TF 不稳定时会停止并跳过，不会盲抓。不要再额外开一个终端同时跑 `mirobot_pick_test_tag.py`。

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/robocom_ws/devel/setup.bash
source /home/eaibot/mirobot_ws/devel/setup.bash
source /home/eaibot/handeye-calib/devel/setup.bash
python2 /home/eaibot/handeye-calib/src/tag_chassis_align_pick_sequence.py \
  --wait-key-between-tags \
  --tag-tf-wait-seconds 12.0
```

默认允许处理 `1,2,3,4`，每一步重新选择当前画面最靠左的剩余 ID。默认红框、低速底盘、TF 稳定检查、抓取速度和回零等待已经写在脚本里。每个 ID 抓完后先回示教 idle，再调用 `/mirobot_startup_home` 执行 `$H`。

如果当前画面一个剩余 ID 都没有，脚本才会原地等待；只要看到任意一个剩余 ID，就会继续进入对准流程。

只测试底盘对准，不抓取：

## 4. 示教和重采

### 首次升级旧 preset

旧版本 1/2 的放置点和 idle 会保留，但旧抓取变换会删除。先用同一个最容易对准的物块示教第一个抓取点，它会建立全局固定吸盘姿态和默认固定接近方向；再依次示教其他 ID 的 XYZ 偏移：

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/mirobot_ws/devel/setup.bash
source /home/eaibot/handeye-calib/devel/setup.bash
python2 /home/eaibot/handeye-calib/src/mirobot_pick_test_tag.py \
  --mode teach_tag_grasp \
  --sequence 3 \
  --preset-file /home/eaibot/handeye-calib/config/tag_pick_place_presets.json \
  --overwrite \
  --assist-front-gap 0.04
```

然后把 `--sequence` 改成 `2`、`3`、`4` 分别重采。版本 3 运行时使用过滤后的 Tag XYZ 加每个 ID 的固定 XYZ 偏移；吸盘姿态和接近方向固定，不跟随 1.45cm 小 Tag 的旋转抖动。这样比赛高度变化会反映到抓取 Z，但 Tag XYZ 抖动超过门限时会拒绝抓取。

### 采集空闲姿态

在 RViz 里把机械臂移动到比赛等待姿态，Plan/Execute 到位后运行：

```bash

source /home/eaibot/handeye-calib/devel/setup.bash

  --mode teach_idle \

  --overwrite
```

### 采集抓取后中转姿态

这个姿态用于“吸住物块并从抓取点退回之后、去放置点之前”。在 RViz 里把机械臂移动到一个高一点、不撞料仓、不扭到关节极限、泵管不缠的位置，Plan/Execute 到位后运行：

```bash

  --mode teach_carry \
  --preset-file /home/eaibot/handeye-calib/config/tag_pick_place_presets.json \
  --overwrite
```

### 只重采某个 tag 的抓取点

放置点已经准时用这个。把 `--sequence 1` 改成要重采的 ID。

```bash

source /home/eaibot/handeye-calib/devel/setup.bash

  --mode teach_tag_grasp \
  --sequence 2 \
  --preset-file /home/eaibot/handeye-calib/config/tag_pick_place_presets.json \
  --overwrite \
  --assist-front-gap 0.04
```

运行流程：

- 确认 AprilTag 窗口里目标 tag 稳定画框，按 Enter 缓存 tag 位姿。
- 脚本自动移动到 tag 前方安全点；`--assist-front-gap 0.04` 表示离 tag 约 4cm。
- 在 RViz 微调吸盘到抓取接触位置，Plan/Execute 到位后按 Enter 记录。

## 5. 关键检查

AprilTag 是否检测到：

```bash
rostopic echo -n 1 /tag_detections
```

确认 RGB 内参不是空值，并且矫正图存在：

```bash
rostopic echo -n 1 /camera/rgb/camera_info
rostopic hz /camera/rgb/image_rect_color
```

`camera_info` 中 `width/height` 必须是 `640/480`，`K[0]`、`K[4]` 和 `P[0]`、`P[5]` 必须大于 0。

TF 是否完整：

```bash
rosrun tf tf_echo base camera_link
rosrun tf tf_echo base tag_1
```

如果 `base -> tag_1` 没有输出，抓取脚本一定不能正常运行。先检查终端 3 手眼 TF 和终端 5 AprilTag。

吸泵服务：

```bash
rosservice list | grep pump
rosservice call /switch_pump_status true
rosservice call /switch_pump_status false
```

启动回零服务：

```bash
rosservice list | grep mirobot_startup_home
rosservice call /mirobot_startup_home
```

## 6. 常用参数

- `--approach-gap 0.03`：抓取前预抓点距离。目标太靠近机械臂导致规划失败时，可以试 `0.01`。
- `--place-approach-gap 0.02`：放置点上方高度。
- `--assist-front-gap 0.04`：示教辅助点离 tag 多远。
- `--teach-settle-seconds 0.8`：示教按 Enter 后等待多久再采样当前姿态。
- `--motion-settle-seconds 0.25`：动作完成后等待关节状态刷新。
- `--startup-home-settle-seconds 3.0`：底盘自动流程每抓完一个 tag 后，调用启动回零 `$H` 后等待多久。
- `--skip-startup-home`：调试时跳过每个 tag 后的启动回零。
- `joint6_max_trajectory_travel_rad:=3.0`：控制器下发前检查原始轨迹的 Joint6 累计转动量。超过时整条轨迹拒绝执行，不修改 RRT 结果；不要为了绕过缠管风险随意调大。

## 7. RGB 内参与手眼标定

先准备已实测格子尺寸的棋盘，下面 `8x6` 和 `0.025` 只是示例，必须替换成你的棋盘内角点数量和格子边长（米）：

```bash

  --size 8x6 \
  --square 0.025 \

  camera:=/camera/rgb
```

```text

```

要求重投影误差不超过 `0.5px`。加载新 RGB 内参后必须重新做一次 eye-on-base 手眼标定：

## 8. 诊断采样

静止小 Tag 连续采样，输出 JSON/CSV：

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/mirobot_ws/devel/setup.bash
python2 /home/eaibot/handeye-calib/src/tag_arm_diagnostics.py \
  --mode tag_static \
  --base-frame base \
  --target-frame tag_1 \
  --tag-id 1 \
  --duration 3.0 \
  --min-samples 10
```

机械臂重复到位测试：临时在 Link6 刚性外壳贴 3-4cm 大 Tag，并在 `tags.yaml` 临时配置为 `id: 5, size: 0.04, name: tool_test_tag`。测试时直接对矫正图运行 AprilTag，不经过只识别 ID1-4 的 YOLO：

```bash
roslaunch apriltag_ros continuous_detection.launch \
  camera_name:=/camera/rgb \
  image_topic:=image_rect_color \
  publish_tag_detections_image:=true \
  show_image:=true
```

到三个安全姿态各做 10 次重复到位采样：

```bash
python2 /home/eaibot/handeye-calib/src/tag_arm_diagnostics.py \
  --mode arm_repeatability \
  --base-frame base \
  --target-frame tool_test_tag \
  --tag-id 5 \
  --trials 10 \
  --duration 1.5 \
  --min-samples 10
```

大 Tag 只用于固定终点测量，比赛抓取前移除，也不要求运动途中一直可见。结果保存在 `/home/eaibot/handeye-calib/diagnostics/`。

检查注册深度是否可用：

```bash
python2 /home/eaibot/handeye-calib/src/tag_arm_diagnostics.py \
  --mode depth_check \
  --base-frame base \
  --target-frame tag_1 \
  --tag-id 1 \
  --duration 3.0 \
  --min-samples 10
```

只有 Tag 框内深度有效率至少 `80%` 且 `mad_m <= 0.005` 时，才考虑后续融合深度；当前比赛抓取默认仍使用过滤后的 PnP 平移。
