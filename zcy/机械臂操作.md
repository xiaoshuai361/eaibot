## 3. 单个 Tag 重采

放置点如果已经准，就不要再覆盖。现在可以把抓取和放置分开采：

- `teach_tag_grasp`：只重采某个 tag 的抓取接触姿态，保留原来的车上放置点。
- `teach_tag_place`：只重采某个 tag 的车上放置点，保留原来的抓取姿态。
- `teach_tag_sequence`：抓取和放置一起采，通常只在第一次建 preset 时用。
  source /opt/ros/melodic/setup.bash
  source /home/eaibot/mirobot_ws/devel/setup.bash
  source /home/eaibot/handeye-calib/devel/setup.bash
  python2 /home/eaibot/handeye-calib/src/mirobot_pick_test_tag.py \
   --mode teach_tag_sequence \
   --sequence 3 \
   --preset-file /home/eaibot/handeye-calib/config/tag_pick_place_presets.json \
   --overwrite \
   --assist-front-gap 0.04

### 3.1 只重采 tag_1 抓取

这是现在最常用的命令。它会读取当前 `tag_1`，自动移动到 tag 前方安全点，然后让你在 RViz 里微调吸盘接触位置。按 Enter 记录后，只更新 `tag_1` 的抓取姿态，不会动原来的放置点。

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/mirobot_ws/devel/setup.bash
source /home/eaibot/handeye-calib/devel/setup.bash
python2 /home/eaibot/handeye-calib/src/mirobot_pick_test_tag.py \
  --mode teach_tag_grasp \
  --sequence 3 \
  --preset-file /home/eaibot/handeye-calib/config/tag_pick_place_presets.json \
  --overwrite \
  --assist-front-gap 0.04
```

运行后按终端提示走：

- 第 1 步：确认 AprilTag 窗口里 `tag_1` 稳定画框，按 Enter 缓存 tag 位姿。
- 第 2 步：脚本自动移动到 tag 前方安全点；`--assist-front-gap 0.04` 表示离 tag 约 4cm，觉得近就调大。
- 第 3 步：在 RViz 微调吸盘到抓取接触位置，Plan/Execute 到位后按 Enter 记录。脚本会默认等 `0.8s` 再读取当前位姿，避免刚执行完时关节状态还没刷新。

新版抓取记录会保存“抓取点相对 tag 中心的 base 偏移 + 示教时的末端姿态 + 示教时的接近方向”。这样物块换到左右不同格子时，抓取点主要跟随 tag 中心平移，减少 tag 姿态抖动带来的 XY 偏差。已有旧 preset 建议对 1-4 都重新执行一次 `teach_tag_grasp`，放置点不用重采。

重采其他物块，把 `--sequence 3` 改成 `--sequence 1`、`--sequence 2` 或 `--sequence 4`。

### 3.2 只重采 tag_1 放置点

只有车上载物仓位置不准，或者放置时腕部/吸盘自转姿态不对时才用这个。运行前在 RViz 里把吸盘移动到对应载物仓释放位置，Plan/Execute 到位后回终端按 Enter。它只更新放置点和放置时的关节姿态，不会动原来的抓取姿态。

```bash

  --mode teach_tag_place \
  --sequence 3 \
  --preset-file /home/eaibot/handeye-calib/config/tag_pick_place_presets.json \
  --overwrite
```

## 4. Tag 抓取要点

- 终端 4 不保存图片，只实时发布 `/tag_yolo_quiet/image_raw`。
- `--yolo-hz` 是 YOLO 推理频率，`--publish-hz` 是发给 AprilTag 的图像频率。
- 终端 5 显示的是最终画面：YOLO 补白图 + AprilTag 识别框。
- `/tag_yolo_quiet/detections_json` 是 YOLO 框结果；底盘对准脚本用它判断 tag 是否进入红框。
- `/tag_chassis_align/debug_image` 是红框 + YOLO 框中心调试图，不会影响 AprilTag 输入图。
- preset 路径：`/home/eaibot/handeye-calib/config/tag_pick_place_presets.json`。
- 抓取记录为相对 tag 中心的 base 偏移，末端姿态和接近方向使用示教时的稳定值；物块左右移动后，抓取点跟随 tag 中心平移。
- 示教辅助点默认泵头水平；最终抓取姿态以 RViz 示教时记录的末端姿态为准。
- 放置姿态记录在 `base` 下；载物仓位置变了才需要重采。
- 放置点只记录释放位姿。抓取后到放置结束不再额外调整 `joint5/joint6`，避免搬运中插入关节对齐导致规划失败。
- 空闲姿态记录为关节角；比赛运行结束后自动回空闲姿态。
- 如果某个物块抓偏，只用 `teach_tag_grasp` 重采对应 tag，别覆盖已经准的放置点。
- 如果放置时报 `MoveIt failed to compute a full cartesian path during taught_place (fraction=...)`，意思是从放置上方直线下放时 MoveIt 中间插值失败。新版脚本会先重试无碰撞检查，再兜底用普通位姿规划，并且异常时会先关泵。
- 如果报 `Invalid Trajectory: start point deviates from current robot state more than 0.05`，意思是 MoveIt 规划时用的起始关节角和控制器读到的真实关节角不一致。新版脚本会等待关节状态稳定后自动重试一次。
- 如果机械臂已经到目标附近但 MoveIt 返回失败，新版脚本会接受当前位姿，不会再重复执行同一个目标。正常流程里仍然会有“抓取后退回、放置后退回”的安全动作。

常用参数：

- `--assist-front-gap 0.04`：示教辅助点离 tag 多远，单位米；觉得太近就调大。
- `--teach-settle-seconds 0.8`：示教按 Enter 后等待多久再采样当前位姿；如果发现“后采样哪个哪个准”，可以调到 `1.2` 或 `1.5`。
- `--approach-gap 0.03`：比赛抓取前，预抓点离最终抓取点多远。
- `--place-approach-gap 0.02`：放置点上方高度。
- `--motion-settle-seconds 0.25`：每次 MoveIt 动作成功后等待 0.25 秒，让 actionlib goal 状态和 `/joint_states` 收尾，减少连续发 goal 造成的回调警告。
- `--home-after-idle`：抓完当前 tag 后，先回示教 idle，再执行 MoveIt named target `home`。底盘联动脚本默认会带这个参数。
- `--dry-run`：只算位姿，不动机械臂、不吸泵。
- `--debug-hold-seconds 30`：保留 RViz 调试点。
- `--velocity-scale 0.05 --acceleration-scale 0.05`：低速真机测试。

RViz 调试点：

- `/mirobot_pick_debug/taught_pre_grasp`
- `/mirobot_pick_debug/taught_grasp`
