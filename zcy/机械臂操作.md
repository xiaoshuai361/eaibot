## 3. 单独测试机械臂抓取

四个 Tag 共用 ID2 的一个示教预抓点 P：吸盘近距离正对物块，但不接触。正式运行先普通规划到 P 后方 `30mm`，在这里开启限位，再保持姿态受保护地直线伸到 P；途中未触发才从 P 继续限位前探。

`--approach-gap 0.030` 只控制 P 后方的安全过渡距离。安全点到 P 使用 `5mm` 步长，P 后接触前探保持每步 `2mm`、最多 `65mm`；两段限位均生效。限位触发后 C++ 停止剩余路点，然后才开泵。

连续抓取也完全相同：每一个 Tag 都重新执行“P 后方 `30mm` → 开启限位 → 受保护地直线到 P → 未触发再前探”，不会从上一个 Tag 的结束姿态直接横向移动到下一个 P。

吸附成功后必须保持原接近方向直线缩回到 P 后方 `30mm`，缩回成功后才允许规划 carry/放置。限位未触发时也先直线退到这个位置，再规划 idle。有 Tag、无 Tag 都执行这一安全顺序；直退失败会终止动作，不会直接转向。

单独抓 ID2：

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/mirobot_ws/devel/setup.bash
source /home/eaibot/handeye-calib/devel/setup.bash
python2 /home/eaibot/handeye-calib/src/mirobot_pick_test_tag.py \
  --mode run_taught_sequence \
  --sequence 2 \
  --preset-file /home/eaibot/handeye-calib/config/tag_pick_place_presets.json \
  --velocity-scale 0.2 \
  --acceleration-scale 0.2 \
  --approach-gap 0.030 \
  --tf-timeout 12.0
```

如果只想检查计算结果而不运动，在命令末尾加 `--dry-run`。日志应依次显示“预抓点后方安全点”和“示教预抓点”，两者相差约 `30mm`。

## 4. 示教和重采

不要用本地 preset 覆盖真机文件。若真机 ID2 当前保存的不是“近距离正对但未接触”的预抓姿态，则只需重教 ID2 一次。

只有以后确实要校正共同抓取位置时，才重教 ID2：

```bash

source /home/eaibot/handeye-calib/devel/setup.bash
python2 /home/eaibot/handeye-calib/src/mirobot_pick_test_tag.py \
  --mode teach_tag_grasp \
  --sequence 2 \
  --preset-file /home/eaibot/handeye-calib/config/tag_pick_place_presets.json \
  --overwrite \
  --assist-front-gap 0.065
```

脚本先自动靠近 Tag；在 RViz 调到近距离正对但不接触的位置后按 Enter。该结果供 ID1~4 共用，不覆盖四个放置点。

### 只重采某个 tag 的放置点

有 Tag 和无 Tag 共用同一组载物仓放置点。运行 `teach_tag_grasp` 时，你在 RViz
最终调好的预抓 Link6 位姿会同时自动保存为共同放置示教起点。因此正常
流程不需要再单独示教起点。

只有想在不改抓取参数的情况下单独重采共同起点时，才使用可选命令：

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/mirobot_ws/devel/setup.bash
source /home/eaibot/handeye-calib/devel/setup.bash
python2 /home/eaibot/handeye-calib/src/mirobot_pick_test_tag.py \
  --mode teach_place_start \
  --preset-file /home/eaibot/handeye-calib/config/tag_pick_place_presets.json \
  --overwrite
```

运行后在 RViz 中 `Plan/Execute` 到满意的向前伸展预抓姿态，再回终端按 Enter。
该可选入口只更新放置示教起点，不改正式抓取参数。

之后重采任一放置点时，脚本会先自动移动到上述共同起点，再提示你从该姿态
使用 RViz 调整到对应载物仓。按 Enter 后保存你最终调整出的 Link6 完整位姿，
包括位置和四元数；不会把四元数强制替换成抓取姿态。

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/mirobot_ws/devel/setup.bash
source /home/eaibot/handeye-calib/devel/setup.bash
python2 /home/eaibot/handeye-calib/src/mirobot_pick_test_tag.py \
  --mode teach_tag_place \
  --sequence 4 \
  --preset-file /home/eaibot/handeye-calib/config/tag_pick_place_presets.json \
  --overwrite
```

`--sequence 4` 可改为 `1`、`2`、`3`。该结果同时供有 Tag 和无 Tag 入仓使用，
无 Tag 不需要重复示教。

## 5. 载物仓投递

投递只需启动终端 2。四个仓内抓取点按 ID 独立，但在有 Tag/无 Tag 两种
投递之间共用，统一保存在 `delivery_presets.json`；每种投递各自使用自己的
过渡点和投递点：

1. 载物仓抓取点：吸盘已贴到物块。
2. 中间过渡点：物块离开载物仓，运动时不碰撞。
3. 投递点：吸泵关闭后物块能落到目标位置。

空闲姿态直接复用 `tag_pick_place_presets.json` 中的 `idle_joint_values`，不用重复采集。
仓内抓取点继续使用现有的 6 个示教关节角；运行时由 MoveIt FK 自动计算对应的末端位姿和“上方 5cm”，不需要重新示教。

三个点分三次运行命令，互不覆盖。每次都先在 RViz 中 Plan/Execute 到位，再回到脚本终端按 Enter。不要手掰机械臂。

单个 ID：

```bash
python2 /home/eaibot/handeye-calib/src/mirobot_delivery.py \
  --mode run_delivery \
  --sequence 1 \
  --delivery-file /home/eaibot/handeye-calib/config/delivery_presets.json \
  --tag-preset-file /home/eaibot/handeye-calib/config/tag_pick_place_presets.json
```

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/mirobot_ws/devel/setup.bash
source /home/eaibot/handeye-calib/devel/setup.bash
python2 /home/eaibot/handeye-calib/src/mirobot_delivery.py \
  --mode run_delivery \
  --sequence 1,2,3,4 \
```

每个 ID 的固定顺序是：MoveIt FK 计算抓取位姿 -> 从当前姿态直接规划到抓取点上方约 `5cm`（投递前不回零） -> 普通关节规划到原示教仓内抓取点 -> 开泵 -> 保持吸盘姿态沿 base `+Z` 直线上升 `5cm` -> 到共享过渡点 -> 到共享投递点 -> 关泵 -> 回共享 idle。
