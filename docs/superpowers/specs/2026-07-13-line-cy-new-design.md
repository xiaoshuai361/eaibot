# line_cy_new 重构设计

## 目标

新建单文件 `robocom_ws/src/line_cy_new.py`，不修改现有 `line_cy.py`。新实现保留双边巡线、斑马线入口停车、车身摆正、左转、直行、右转和出口恢复，同时减少状态、参数和重复检测路径。

## 视觉与巡线

画面缩放到 640 像素宽后提取黑色二值图。正常巡线在若干水平扫描行上从图像中心分别向左、向右寻找遇到的第一个黑色段，因此天然忽略两条车道边界以外的文字、斑马纹和其他黑块。双边都存在时取内边缘中点；只剩一边时按学习到的车道宽度补出另一边。正常双边测量以指数平均更新车道宽度。

## 斑马线与横条

斑马纹使用旋转矩形的面积、长宽比、方向一致性和横向分布确认。停车横条不要求完整进入画面：在条纹组下方区域运行概率 Hough，任一足够长线段只要覆盖至少一个条纹中心、位于该条纹下方且方向近似垂直，即确认局部横条。连续帧确认后低速靠近，横条到近端后原地摆正。

## 路口补线

- `straight`：从中心向右取得每行第一条边界点，使用确定性直线 RANSAC 拟合 `x = a*y + b`。偏离模型的内侧圆角和红绿灯轮廓作为离群点拒绝。模型短暂丢失时保留最近可靠直线，并按车道宽度向左生成虚拟边界和车道中心。
- `left`：跟随左边界并向右补线。
- `right`：跟随右边界并向左补线。

路口退出优先使用连续出口横条；若横条漏检，则在入口斑马线清除后，以正常双边界连续恢复作为后备；最长通过时间提供安全保护。

## 状态机

`FOLLOW -> APPROACH -> ALIGN -> MANEUVER -> FOLLOW`。检测丢失或摆正超时进入 `WAIT` 并保持停车。`DRY_RUN` 默认开启，任何运动发布必须同时满足非 dry-run。

## 参数

顶部只保留常用参数：相机与安全开关、三种速度、最大角速度、PID、转向平滑、黑色阈值、ROI、车道宽度和单边补线距离。RANSAC、形状比例、确认帧数等稳定算法阈值放在内部常量，不接 ROS 参数。

## 开源方案取舍

- `ljfanxi/lane-detection-RANSAC` 展示了 Hough 取点与 RANSAC 曲线拟合组合；本项目采用其鲁棒拟合思想，但将二次模型改成直线模型以主动拒绝入口圆角。
- `udacity/CarND-Advanced-Lane-Lines` 的滑窗/分层取点适合连续车道；本项目采用分层扫描思想，但不使用会贴合圆角的多项式模型。

## 验证

独立测试覆盖中心向外取线、外部黑块排除、单边补线、局部横条、RANSAC 离群点拒绝、模型短时保持、三种动作、出口横条优先和双边恢复后备。最后运行单元测试、`py_compile` 和 `git diff --check`。
