# zcy_last 使用命令

## 1. 进入运行环境

```bash
source /opt/ros/melodic/setup.bash
source /home/eaibot/robocom_ws/devel/setup.bash
source /home/eaibot/mirobot_ws/devel/setup.bash
source /home/eaibot/handeye-calib/devel/setup.bash
conda activate ww
cd /home/eaibot/robocom_ws/src
```

正式比赛由 `zcy_last.main` 自动启动和关闭自己管理的底盘、Astra、MoveIt、手眼 TF、Tag 检测与抓取进程，不要提前手动启动相同节点。

## 2. 四种启动方式

不执行机械臂抓取，只运行九路口循迹、任务 YOLO 和红绿灯判断：

```bash
python3 -m zcy_last.main
```

仅在循迹开始前执行 B 点有 Tag 抓取，成功抓取 2 个目标：

```bash
python3 -m zcy_last.main --tag-pick --tag-pick-count 2
```

仅在第 3 个路口完成后执行 A 点无 Tag 抓取，成功抓取 3 个目标：

```bash
python3 -m zcy_last.main --untagged-pick --untagged-pick-count 3
```

B 点和 A 点都执行抓取：

```bash
python3 -m zcy_last.main \
  --tag-pick --tag-pick-count 2 \
  --untagged-pick --untagged-pick-count 3
```

`--tag-pick-count` 和 `--untagged-pick-count` 只能填写 `1..4`。数量表示必须成功抓取的目标数，不是固定类别顺序；程序按当前可见目标从左到右选择。

## 3. 临时关闭抓取

即使 `config.py` 中默认打开了抓取，也可以通过命令临时关闭：

```bash
python3 -m zcy_last.main --no-tag-pick --no-untagged-pick
```

命令行开关优先于 `config.py` 顶部的默认开关。

## 4. 使用人工启动的 ROS 依赖

仅在调试且全部 ROS 依赖已经人工启动时使用：

```bash
python3 -m zcy_last.main --external-ros
```

`--external-ros` 模式不会启动、检查或关闭外部 ROS 进程，不建议用于正式比赛。

## 5. 失败处理

发生目标不足、Tag TF 超时、抓取失败、共享摄像头占用或依赖进程退出时，任务进入 `PICK_FAILED` 并永久停车。不要直接继续运行，先查看：

```text
/home/eaibot/logs/zcy_last/<启动时间>/
```

修复故障后重新启动整套任务。完整状态机和摄像头切换说明见同目录 `README.md`。
